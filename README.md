# psy120L-final-reproducible-report
Developmental Experiences: Shaping Students' Experience In Academic Environments

This repository contains the final published HTML version of my PSY120L final reproducible report. 
The current study aimed to answer the question: How do students' academic and developmental experiences shape their self-efficacy and achievement motivation?
This report was created using Quarto and R Studio. 
The published report file is index.html. 
The dataset is not included in this repository.
